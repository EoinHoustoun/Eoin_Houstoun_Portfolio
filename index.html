ResearchBSc dissertation · First

Validation Procedures in Machine Learning

10 validation methods compared on 1,316 football transfers; the final model beat the baseline by 43%.

Bootstrap vs k-fold vs LOOInternal-external validationR² 0.70

Fuzzy-matched FIFA player data (106k players, 2017-21) to Transfermarkt fees for 1,316 top-five-league transfers. Compared split-sample, k-fold, repeated k-fold, Monte Carlo CV, leave-one-out, bootstrap and internal-external validation. Bootstrap matched the best error with higher precision from fewer iterations, leave-one-out was optimistic and high-variance, and validation exposed an overfitting random forest, so the simpler log-linear model (R² 0.70) was chosen.
